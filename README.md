# 图片压缩网站

这是一个简单的在线图片压缩工具，可以帮助用户轻松压缩图片文件大小，同时保持图像质量的平衡。

## 功能特点

1. 支持上传PNG、JPG等格式的图片
2. 允许用户选择压缩比例
3. 提供压缩前后的图片预览
4. 显示压缩前后的文件大小对比
5. 可下载压缩后的图片

## 页面结构

- **顶部区域**：标题与简短说明
- **上传区域**：拖放区域和文件选择按钮
- **预览与控制区域**：
  - 左侧：原图预览与信息
  - 右侧：压缩后图片预览与信息
  - 中间：压缩设置控制器
- **底部区域**：下载按钮和其他操作按钮
